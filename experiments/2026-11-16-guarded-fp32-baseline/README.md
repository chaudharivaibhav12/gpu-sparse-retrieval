# Guarded canonical FP32 baseline qualification

Full **8,841,823 passages**, 500 calibration queries, RTX 4070, k=10, batch=1: range median **0.685848 ms**, canonical U64 GPUSparse **6.895403 ms**, guarded canonical FP32 GPUSparse **6.008201 ms**. FP32 uses 12.75% less query time than U64 by the paired estimator; range remains **8.43×** faster than FP32 (conditional 95% interval 8.31–8.56).

The experiment asks whether widening GPUSparse scoring to U64 disadvantaged the prior control. It reuses the original pinned FP32 scatter kernel with exact-integer domain guards and the same canonical numeric-ID selector. Our range algorithm is unchanged. See the [report](report.md), [full frozen protocol](configs/protocol.json), [team handoff](TEAM-CONTEXT.md) and [standalone public replay](analysis/replay_public.py).
